# 韩叙短视频选题 Skill

不知道拍什么时，从你的专业经历、目标观众和当前问题里寻找灵感，补充一批可以挑选、持续积累的短视频备选题。

范围包括专业经验、个人发展、做业务及其他与你相关的场景，不局限AI工具。每条都给真实参考、对你的启发和具体回想提示，帮助你想到：“这件事我遇到过，有东西可以讲。”

适合有专业积累、希望做内容表达或发展个人业务的人。没有产品、客户或成熟账号也能开始。自己的背景和观众由你补充，包内没有预填作者的个人情况。

当前版本：`v0.2.2`。需要能读取Skill的AI助手；主动搜索还需要该助手当前具备搜索或浏览能力。本包不附平台账号、采集服务或API密钥。

## 安装与更新

完整步骤见[安装与更新](INSTALL.md)：安装完整技能 → 确认位置和版本 → 开始任务；更新前保留个人记录与本地修改，将旧版备份到技能发现目录之外，失败可恢复。


```text
用 $hanxu-video-topics 帮我找一批短视频灵感。我做过【经历】，希望给【观众】看，最近关心【问题】。先检查可访问来源，再按实际能力检索；每条给参考、启发和具体回想提示。先不写稿，不编我的经历。
```

主动检索需要宿主当前有搜索/浏览能力及自己的正常平台会话；无联网能力可先整理给定材料。仅对话使用无需Python，本地题库工具需要Python3.9以上。

## 第一次使用：直接告诉它你的情况

安装后，在自己用于内容创作的对话或工作目录里说：

```text
用 $hanxu-video-topics 帮我补充一批短视频灵感。
我做过：项目管理和客户沟通。
希望谁看：刚开始独立接项目、有经验但不知道怎么表达自己的人。
最近关心：找客户、报价、处理额外要求，也可以从个人发展找灵感。
请先检查你能访问哪些来源，再实际检索。每条给出参考链接、对我的启发，以及我可以回想的具体事情。结果直接发在对话里，让我自己挑选，先不写稿。
```

上面是可替换的使用示例，不是你的默认资料。你也可以只说“我做过采购，想讲一点自己工作的经验，帮我找些灵感”，让助手问必要的信息，不必先填JSON或想好商业模式。

更换自己的背景、只整理给定材料、反馈选择、继续补库与保存方式，见[使用说明](USAGE.md)。

想先看完整过程，可以看[餐饮运营用户首次使用示例](USAGE.md#restaurant-example)：一句话提供背景、必要补问、真实检索得到的15条灵感，以及选择、纠偏和保存的说法。

## 你会拿到什么

- 一批不同问题的灵感备选，按实际范围和来源供给决定数量。
- 每条的参考来源、给你的启发、具体回想提示和待补信息。
- 少量值得先看的方向，以及证据不足但有启发的储备，两者分开展示。
- 如需保存，可在你自己的目录积累配置、题库和选择反馈，下次继续补充。

例如参考题面是“客户说只改一点，最后却重做三天”，它可以提示你：“回想一次对方说只改一点的沟通：你当时怎样答应，后来多做了什么？”这是演示，不代表真实来源或你有过这段经历。

备选不等于已选。你挑中以后才展开观点、案例和稿件；本Skill不会自动剪辑、发布或联系别人。

## 搜索条件与费用

助手能搜索或浏览时，才实际查找并说明覆盖范围。平台需要登录时使用你自己的正常会话；访问不到会说明缺口，不会把没读到的页面当已核验。没有搜索能力时，可以整理你提供的文本、截图或可读取来源，也可以列出待验证探索问题，两种结果会明确区分。

外部视频默认只看标题、发布介绍、标签及可见互动，不下载、转写或推断完整观点。未知粉丝不称低粉，点赞也不代表你的内容一定有效。

方法本身无需单独申请API密钥或安装其他业务Skill；AI助手、可选工具和服务按其实际账户与费用运行。选择本地题库工具时需要Python 3.9以上，仅使用标准库；不保存文件也可在对话中使用。

## 配置、隐私与兼容性

用户背景、观众、经历线索、话题范围、偏好和排除项从空白开始，可以边用边补。AI主题是可选范围，不是默认限制。你的资料与题库放在自己的工作目录，技能安装目录保持独立，升级不应覆盖用户记录。

面向Codex提供安装与调用说明；其他支持`SKILL.md`的助手可按其安装机制尝试，未逐客户端验证。Mac与Windows使用相同技能文件；实际搜索权限、平台登录和真人使用效果仍需在各自环境确认。

## 版本与维护

`v0.2.1`补齐公开安装、使用和排错说明，发布包解压后直接包含技能入口。`v0.2.0`的广泛问题探索、每题回想提示和空白配置继续保留。本包改编自韩叙短视频工作流的选题Agent，作者身份、固定词池、电脑环境和私人资料不作为用户默认值。

技术检查与本地回放不能证明用户一定获得启发、拍摄、流量或收入。版本的实际检查结果见[GitHub Actions](https://github.com/hanxu66/hanxu-video-topics/actions)和对应Release说明。

开发者在仓库根目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/build_release.py --output /你选择的输出路径/hanxu-video-topics-v0.2.2.zip
```
