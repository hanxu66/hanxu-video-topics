# 用户配置

首次只了解会改变检索和推荐的少量信息，边用边补。下面是记录结构，不要求用户先填表；已有材料直接提取，区分本人确认、AI暂定和未知。

| 内容 | 决定什么 |
|---|---|
| 专业、经历、目前想讲的方向 | 在什么领域找灵感，哪些判断可能由本人展开 |
| 目前阶段、正在做的事与关心的问题 | 个人发展、职业选择、业务和生活中有哪些真实处境可探索 |
| 愿意分享的经历线索 | 用户可选填几件做过的事、一次转折或被反复问的问题；不用先交完整履历和故事 |
| 目标观众和当前处境 | 什么问题值得找，不预设观众已有成熟业务 |
| 内容目标 | 表达专业、吸引相关观众、建立信任或产品理解；不要求每条卖东西 |
| 平台与形式 | 抖音、小红书或指定平台；口播、演示、访谈等由用户选择 |
| 已有关键词、账号与喜欢的作品 | 复用已有探索；账号和单条作品分别判断 |
| 已讲内容、旧库与反馈 | 同问题查重，识别新条件和可补充部件 |
| 偏好、排除项和现实资源 | 愿不愿露脸、可投入时间、能否演示等 |
| 本轮范围与数量 | 找新灵感、仅整理、旧题复查或反馈；数量可调 |

最简开场可以是：“我做过什么、想让哪类人看、最近想讲什么、有无不想模仿的内容。”没有完整商业模式也能开始。方向尚未确定时选一个暂定探索范围并注明假设，不从平台热度替用户决定职业、业务或转型。

新用户没有旧评分、发布历史或采用记录时保持空。品牌称呼、专名纠正、AI主题限制、内容类型及风格以该用户为准，不继承作者设置。

## 可补充的配置

[空白配置模板](profile-template.json)随包提供；本地工具初始化时将它复制到用户目录的`profile.json`。所有背景、受众、经历和偏好从空开始，字段可逐步补充，不能把模板当调查问卷要求一次填完。没有文件工具直接在对话维护相同信息。

- `background`：本人专业/岗位、领域、擅长的事和目前阶段；`experience_seeds`：愿意分享的经历线索；`current_questions`：当前关心的问题。
- `direction`、`audience`、`goals`：想讲的方向、希望谁看、做内容的目的。保留专业表达和个人业务的适用人群，不预设年龄、大厂背景、职业状态或已拥有产品客户。
- `topic_scope.include/exclude`：探索与排除范围；`topic_scope.ai_relevance`由用户指定。为空时不预设AI主题，可按专业经历、个人发展、业务或其他相关场景找问题；这些是探索视角，不是每轮都要填满的固定分类。
- `platforms`、`formats`、`keywords`、`reference_accounts`、`preferences`、`exclusions`、`scope`：平台形式、已有来源、偏好和本轮边界，全部由用户资料确定。
- `confirmation`：记录本人确认、AI暂定和未知的依据；猜测不写成已确认。

例如用户说“我做过采购，想给刚负责项目的人看，最近纠结怎样与供应商沟通”，即可从已知内容开始，不追问其是否有AI工具、成熟产品或成功生意。年龄、品牌、私有词池、具体客户和工作流不从作者或其他用户继承。同一工作目录只放同一用户或获授权的同一项目。

## 跨轮背景补充

`round_supplements`可保存用户逐轮补充的背景与范围。每条原话与其所属轮次一起保存；不要把`received_this_round=true`、注释“本轮新提供”当成永久有效的当前轮标记。恢复时原话中的“本轮”“下轮”指该事件当时，本次是否收到新材料以本次实际输入为准。

新记录可用`round_id`标明所属轮次，`recorded_at`保存真实记录时间，`feedback_ref`关联本用户题库中对应的反馈。事件时间与本次修复时间分别记录。原话的本轮限制不因跨会话而自动变成长期偏好。

旧记录仅在有明确修复授权时处理：先逐字节备份；由原来源中的轮次和同文反馈核对归属，再移除会随轮次失效的布尔标记及歧义说明。保留原话、模拟标记、原来源和反馈范围；若借用关联反馈的`at`作为`recorded_at`，用`recorded_at_basis`说明它是反馈记录时间，不能声称为独立核实的接收时间。所属轮次、时间或关联无证据就保留未知，不取当前时间补历史。

例如下面仅为合成格式，时间不表示本包实际运行：

```json
{
  "round_id": "synthetic-round-a",
  "recorded_at": "2026-10-22T12:00:00+08:00",
  "recorded_at_basis": "关联反馈记录时间，独立接收时间未记录",
  "feedback_ref": "library.json#/feedback/0",
  "quote": "合成原话：这一轮先不讲软件操作。",
  "simulated": true
}
```

普通读取或导出不自动迁移用户配置；修复后的记录下轮仍属于原轮次，不需要每轮翻转布尔值。
