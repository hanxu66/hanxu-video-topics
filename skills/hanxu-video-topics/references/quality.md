# 质量与状态

## 收录与推荐分开

入库至少有真实可回读来源、具体用户问题或可借题面、对本用户的启发、具体回想提示、状态及必要缺口。可缺最终观点、本人案例和结构；不要求当下能拍。

| 状态 | 使用依据 |
|---|---|
| 储备题 | 有具体启发，尚未全部通过优先推荐判断 |
| 待补证据 | 缺会影响来源或兴趣判断的信息，注明缺项和补齐用途 |
| 待补角度 | 问题有价值，当前讲法太泛、无增量或未适配 |
| 只借题面 | 整题不合适，某问题呈现有可回读用途；未读正文不说借完整结构 |
| 优先备选 | 下方判断有实际依据，值得优先考虑，仍待用户挑 |
| 已选 | 有本人具体选择或明确委托且实际代选，保留原话 |
| 已拍／已发布 | 分别有用户确认或实际凭据，不根据已选推断 |
| 暂缓／不再使用 | 按原话范围记录，暂缓保留复查条件 |

身份和用途均不足只留线索，不冒充资产。无真实来源的AI延展标“联想待验证”，附于原题或单列，不算平台搜到或有证据的入库数。本人观点可引用本次对话，不强制外部对标。

## 优先备选判断

逐项说明依据与未知，不用总分抵消缺项：

1. 人群与阶段：观众能认出自己的处境；专业题可以窄，广泛性在该用户目标观众内判断，不预设成熟业务。
2. 观看理由：具体阻碍、选择、机会或可感知结果，解释为何愿意看。
3. 实质收获：新信息、用途、解释、解法或判断。基础题也可有用，换词和夸张反转不算增量。不要求全网首创或刻意反对参考。
4. 来源兴趣：外部作品看同平台、发布时长、点赞、可见收藏/评论、作者体量及可比作品。优先低粉高互动，粉丝未知不称低粉，播放未知不算播放互动率。明显弱互动不能因专业有用变成优先备选。本人主动问题按实际需求依据注明，别伪造外部验证。
5. 本人展开可能性：回想提示对应其已知背景和具体问题，能指向某个人、一次沟通、选择或变化，不是统一填“结合自己的经历”。未知故事不补造，不依赖复制他人经历、特殊身份、独占资源或未验证操作。不要求选题前备齐论证和成功案例。
6. 清楚、适时、可承担：一句话能听懂，查重后有具体新用途，投入及时效适合用户；未确认条件保持暂定。

不设跨平台统一点赞、粉丝上限、比率或及格分；用户可补自己的阈值并标为其设定。没有统一数值不等于互动没有底线。题面证据只支持题面判断，作者完整观点及内容质量未知。

## 反馈与检查

区别源问题不合、AI改写偏离、只喜欢表达、已经讲过、材料待补、当期不想拍、证据不足。反馈只改对应范围；只选一条，其余原状态；未回复不是否定，认可方法不是选中。长期偏好进入该用户配置，单例不变所有用户规则。弱互动被指出时复核同批其他优先备选。

补来源保留原状态；有新证据且本次明确复评时，按[明确复评](tools.md#明确复评)单独记录依据。不能因导入缺省成储备题而替旧题升降状态，用户决定继续由反馈原话保护。

收尾检查：实际范围由用户背景和要求决定，未无依据收窄到AI工具；每题有出处、启发和具体回想提示；原文与联想分离；新增题/补旧题/来源数分别计；无同义凑数；可挑选项充分呈现；状态有凭据；未自动写稿发布；文件可读、用户配置独立且不含作者预设。

结论写通过、需修复或未验证。结构检查、合成演练不能证明真人愿意拍或传播获客效果。实际价值观察用户是否想起自己的经历、题目是否具体、是否选择与拍摄，分别记录，不用入库数量代替。
